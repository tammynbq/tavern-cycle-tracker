# 生理紀錄小幫手 Cycle Tracker

SillyTavern / TauriTavern 前端擴充。讓 AI 在對話中幫你記錄經期、親密、症狀、心情等**真實**紀錄，並在每次生成時把摘要（週期統計、下次預測、近期紀錄、AI 自己的備忘）注入提示詞。

## 運作方式

- AI 在回覆最後加上隱藏標籤，插件解析後會**從訊息中移除**，畫面上看不到：
  - `<ct-log type="period_start" date="2026-10-16">備註</ct-log>` 新增紀錄
  - `<ct-log id="e3" date="...">...</ct-log>` 修改；`<ct-del id="e3"/>` 刪除
  - `<ct-memo>內容</ct-memo>` AI 自己的小本本（可修改、刪除）
- 使用隱藏標籤而非函數呼叫：任何模型都能用，也不會因為工具呼叫多送一輪上下文，比較省 token。
- 重新生成或刪除訊息時，該訊息造成的變更會自動撤銷；切回舊的 swipe 會恢復。
- 紀錄依**角色卡**分開保存（群組聊天以群組為單位），存在本機的 `settings.json`。

## 安裝

TauriTavern／SillyTavern → 擴充功能 → 安裝擴充功能 → 貼上本倉庫的 Git 網址。
或者把整個資料夾放進 `data/default-user/extensions/tavern-cycle-tracker`。

## 設定

在擴充功能面板的「生理紀錄小幫手」裡可以：

- 看月曆：經期（實際／推估）、預測經期、排卵期與排卵日，以及 ❤️ 親密、🤕 症狀、💭 心情等標記；點某一天可以看當天紀錄，並直接用那天的日期新增
- 手動新增／修改／刪除紀錄與「他的小本本」（各區塊可摺疊）
- 設定注入位置與深度、列出筆數與天數（筆數越少越省 token）
- 自訂類型（每行一個，`代號=名稱`，例如 `pill=避孕藥`）
- 預覽注入內容、匯出／匯入 JSON

## 注意

週期預測與排卵期都只是依平均天數推算的估計，**不能當作避孕或醫療依據**。

## 給其他插件用

`globalThis.CycleTracker.getStatus()` 會回傳目前角色的週期狀態（`inPeriod`、`periodDay`、`daysUntilNext`、`late` 等），「主動訊息」插件就是用它來在經期前後主動關心。
